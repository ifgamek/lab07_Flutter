# RPG - игра
В данной программе представлена игра в стиле rpg, в которой вам предстоит выстоять против вашего противника. В данной игре вы сможете выбрать один из 3 классов: Воин, Маг и Лучник. Бой проходит без вашего участия, а по завершению битвы будет объявлен победитель.

# Запуск
1. Клонировать репозиторий: `git clone <url>`
2. Перейти в папку: `cd lab7_rpg`
3. Установить зависимости: `dart pub get`
4. Перейти в папку с игрой: `cd bin`
5. Запуск: `dart lab07_rpg.dart`
